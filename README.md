# Crypto Market - BNB Smart Chain Swap Platform

A decentralized crypto swap application built on top of the 0x Protocol. This platform allows users to securely connect their decentralized wallets (like MetaMask or Trust Wallet) and instantly trade BNB and BSC tokens.

## Features
- **0x Protocol Integration:** Powered by industry-standard secure smart contracts.
- **Affiliate Monetization:** Earns a 1% commission on every successful swap transaction, routed directly to the configured wallet address.
- **Mobile Responsive:** Clean, modern, and dark-themed user interface optimized for all mobile and desktop devices.
- **Low Gas Fees:** Deployed on BNB Smart Chain (BSC) for ultra-fast and cost-effective transactions.
